# Car 1 Firmware

Place the latest tested Arduino sketch here as `car1.ino`.

The repository currently documents the known-working ESP32 DevKit V1 wiring and behavior, but the actual firmware source has not yet been uploaded. Do not treat a reconstructed sketch as the tested version.

## Expected setup

- Board: ESP32 Dev Module (ESP32 DevKit V1)
- Wi-Fi access point SSID: `ESP32_Car`
- Wi-Fi password: `12345678`
- Control page: `http://192.168.4.1`
